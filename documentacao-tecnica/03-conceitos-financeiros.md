# Conceitos Financeiros Para Leigos

Este documento explica os termos usados no Araripe Invest após o reposicionamento educacional e informativo do produto.

## Acompanhamento De Ativos

Acompanhar um ativo significa observar dados, fundamentos, preço, indicadores e premissas ao longo do tempo. No Araripe Invest, esse acompanhamento é informativo: o sistema organiza dados e alertas, mas não orienta conduta de investimento.

## Modelo De Estudo

Modelo de estudo é um conjunto de critérios usados para analisar um ativo. Exemplos:

- qualidade fundamentalista com preço razoável;
- dividendos sustentáveis;
- crescimento rentável com tendência longa saudável.

Um modelo de estudo não é uma ordem, uma indicação personalizada ou uma decisão pronta. Ele apenas mostra quais critérios foram atendidos, parcialmente atendidos ou bloqueados.

## Screener

Screener é uma lista ordenável por critérios. O usuário pode filtrar e ordenar ativos por indicadores, qualidade dos dados, setor, valuation educacional e estado do estudo.

O screener não deve ser apresentado como lista de melhores ativos ou decisões a tomar.

## Fundamentos

Fundamentos são dados da empresa, como receita, lucro, margens, dívida, caixa, patrimônio, dividendos e fluxo de caixa. Eles ajudam a entender a qualidade econômica do negócio.

## Frescor Fundamentalista

Frescor fundamentalista indica se o dado contábil usado ainda é recente. O sistema deve avaliar o período contábil (`most_recent_quarter`) e o prazo esperado do próximo demonstrativo, não apenas a data em que o dado foi processado.

## Valuation Educacional

Valuation educacional compara preço atual, múltiplos e premissas para criar uma referência de estudo. Ele não define uma decisão operacional.

## Preço De Referência Do Estudo

Preço de referência do estudo é um valor calculado a partir de premissas do modelo, como preço justo estimado e margem de segurança. Ele serve para comparação educacional.

## Faixa De Observação Do Estudo

Faixa de observação do estudo é um intervalo usado para acompanhar como o preço se comporta em relação às premissas. Ela não é uma faixa de ordem.

## Margem De Segurança

Margem de segurança é a diferença entre o preço atual e uma referência calculada pelo estudo. No produto, ela deve ser apresentada como indicador educacional, com premissas e limitações.

## Limiar Inferior De Preço Definido Pelo Usuário

É um valor informado pelo usuário para receber alerta quando o preço cruzar um limite inferior. O alerta deve dizer apenas que o limiar foi atingido.

## Limiar Superior De Preço Definido Pelo Usuário

É um valor informado pelo usuário para receber alerta quando o preço cruzar um limite superior. O alerta deve dizer apenas que o limiar foi atingido.

## Ponto De Reavaliação

Ponto de reavaliação é uma condição que pede nova leitura do estudo, como dado desatualizado, premissa alterada, queda de margem, mudança de dívida ou alteração relevante de tendência.

## Score De Aderência

Score de aderência mede quanto um ativo atende aos critérios do modelo de estudo. O score não mede adequação ao usuário e não deve ser exibido como decisão de investimento.

## Liquidez

Liquidez é a facilidade de negociar um ativo sem distorcer muito o preço. No Araripe Invest, baixa liquidez pode bloquear um estudo ou gerar alerta de qualidade.

## Qualidade Dos Dados

Qualidade dos dados avalia completude, consistência, fonte, data de referência e período contábil. Dados ruins bloqueiam modelos de estudo e alertas.

## Alertas Informativos

Alertas informativos são eventos objetivos:

- limiar de preço atingido;
- dado atualizado;
- dado desatualizado;
- indicador fora do intervalo do estudo;
- premissa alterada;
- qualidade de dados bloqueada.

Eles não incluem verbos de ação operacional.

## IA Generativa

IA generativa pode explicar contexto macro/setorial com fontes externas auditáveis. Ela não pode preencher dados macro por memória, orientar conduta ou substituir regras determinísticas.

## Backtest

Backtest é testar uma regra com dados históricos. No Araripe Invest, o backtest deve ser tratado como estudo educacional e não como promessa de retorno futuro.
